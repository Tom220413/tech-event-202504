# テスト環境構築タスク

## タスク概要
テスト駆動開発のためのテスト環境構築

## 要件
- Jest + React Testing Libraryの導入
- MSW（Mock Service Worker）の設定
- カバレッジ設定（80%以上）
- テスト用ユーティリティ関数の作成
- package.jsonの更新

## テスト要件
- テスト環境が正常に動作することを確認
- モックサーバーがAPIリクエストを適切に処理
- カバレッジレポートが生成される
- 既存のコードが動作することを確認

## 技術的制約
- Next.js 15.1.8との互換性
- Supabase認証のモック化
- 既存のpackage.jsonとの整合性
- 既存のESLint設定との整合性

## 期待結果
- `npm test`でテストが実行できる
- カバレッジレポートが生成される
- 既存の開発環境に影響がない

## 実装順序
1. package.jsonの依存関係追加
2. Jest設定ファイルの作成
3. MSW設定ファイルの作成
4. テスト用ユーティリティの作成
5. 動作確認テストの作成

## 注意事項
- 既存の開発環境を壊さないように注意
- 段階的に実装して動作確認を行う
- エラーが出た場合は適切に修正する
